# lumen-calendar

Google Calendar on [Rokid Lumen](https://github.com/beyondlevi/rokid-lumen) glasses, built as a Meta
Ray-Ban Display web app with the official UI Toolkit for Meta Ray-Ban Display: today's agenda, the
week, event details with your reply, and new events dictated or written with the band.
